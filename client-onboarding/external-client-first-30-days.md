# External Client First 30 Days

## Week 1: Onboard

- Intake complete; agents deployed; verify active.
- Asset scope confirmed; escalation contacts verified.
- Baseline alert volume captured.

## Week 2: Baseline

- First vulnerability scan (safe discovery, authorized window).
- Noise tuning: client-specific sources identified.
- Escalation test: P3 test alert -> client contact responds.

## Week 3: Review

- First draft scorecard; client feedback on format/language.
- Critical findings review + remediation plan.

## Week 4: Deliver

- First monthly scorecard delivered.
- 30-day review: coverage, alerts, vulns, posture.
- Adjust monitoring scope per feedback.

## Success criteria

- Agents 100% active (7+ days).
- No unaddressed critical findings.
- Client acknowledges scorecard.
- Offboarding path documented (offboarding-checklist.md).
