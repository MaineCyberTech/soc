# Quarterly Review Prep Checklist (Phase 9)

## 30 days before review
- [ ] Schedule review meeting with client
- [ ] Export alerts (quarter window) from indexer
- [ ] Export incident list from IRIS
- [ ] Run vulnerability scan (if scheduled)
- [ ] Verify backup success logs

## 14 days before
- [ ] Draft quarterly-security-review.md (template)
- [ ] Populate SLA metrics (coverage, MTTA/MTTR, escalation compliance)
- [ ] Endpoint health (active %, FIM, syscollector)
- [ ] Vulnerability remediation status
- [ ] Next-quarter plan draft

## 7 days before
- [ ] Internal QA (client-safe check - no secrets, no internal paths)
- [ ] Operator approval
- [ ] Send agenda + metrics to client

## At review
- [ ] Present summary, risks, recommendations
- [ ] Capture client feedback/action items

## After
- [ ] Store final review in reporting/output/client/
- [ ] Update scorecard with review outcomes
- [ ] Log action items with owners

## No secrets

No secret values printed.
