## What's measured each month

| Area | Description |
|---|---|
| Endpoint coverage | Agents managed, active, offline |
| Alert activity | Alert counts by severity class |
| Confirmed incidents | Real security events + resolution |
| Vulnerabilities | Critical/high findings open, remediated |
| Deception hits | Canary touches (if canaries deployed) |

| Overall posture | Good / Fair / Needs attention + summary |
