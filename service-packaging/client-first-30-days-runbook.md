# Client First 30 Days Runbook

## Week 1: Onboard

- Intake form complete; escalation contacts verified.
- Agents deployed per endpoint checklist; verify Active.
- Asset scope + network map confirmed.
- Scan/canary authorization signed.

## Week 2: Baseline

- First vulnerability scan (safe discovery, authorized window).
- Alert baseline captured per client.
- Escalation test (P3 test alert -> client responds).

## Week 3: Review

- Draft scorecard; client feedback on format.
- Critical findings review + remediation plan.

## Week 4: Deliver

- First monthly scorecard delivered.
- 30-day review: coverage, alerts, vulns, posture.
- Adjust scope per feedback.

## Success criteria

- Agents 100% active 7+ days.
- No unaddressed critical findings.
- Client acknowledges scorecard.
- Offboarding path documented.
