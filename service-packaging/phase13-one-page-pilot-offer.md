# Phase 13 One-Page Pilot Offer

## Managed Security Monitoring Pilot

A limited Linux-first pilot for organizations that want practical monitoring, vulnerability visibility, and monthly security reporting without a broad rollout.

## Includes

- Approved Linux endpoint monitoring
- Endpoint health verification
- Optional vulnerability scan with written authorization
- Monthly scorecard
- Escalation matrix

## Excludes initially

- Windows monitoring
- Deception/Canarytokens
- Automated blocking/quarantine
- Invasive scans without separate written approval
